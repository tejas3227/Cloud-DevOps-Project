CREATE DATABASE person_registration;  
USE person_registration;
CREATE TABLE people (
    id INT AUTO_INCREMENT PRIMARY KEY,
    full_name VARCHAR(100) NOT NULL,
    email VARCHAR(150) NOT NULL UNIQUE,
    phone VARCHAR(20) NOT NULL,
    city VARCHAR(100) NOT NULL,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

AUTO_INCREMENT: Automatically generated unique ID
UNIQUE: Duplicate email addresses are prevented 
DEFAULT CURRENT_TIMESTAMP: Automatically records the registration date and time

SHOW TABLES;  #verify tables
DESCRIBE people;   #to see people table columns

2. Set up Flask backend
We'll create a virtual environment so the packages for this project stay separate from your other Python projects.
python -m venv venv     (create virtual environment)
.\venv\Scripts\Activate.ps1       (to Activate the virtual environment)
python -m pip install --upgrade pip    (Install the required packages)
pip install Flask mysql-connector-python python-dotenv     (install Flask, the MySQL connector, and environment-variable support)

Package     	                Purpose
Flask	                        Runs the backend web application
mysql-connector-python	        Connects Python to MySQL
python-dotenv	                Loads database credentials from a local .env file

3. Create Flask backend
Create app.py and write the code logic to connect to database.
create .env and add database name hostname and password and create .gitignore file and add .env into it so it wont be commited.
Create requirements.txt and add dependencies of project there.
Now test the connection of Flask backend to database using below command:
python -c "from app import get_db_connection; c = get_db_connection(); print('MySQL connection successful!' if c.is_connected() else 'Connection failed'); c.close()"

Folder Structure Explaination:
__pycache__ : It stored the byte code generated by python so when we run code next time it puts cache from this folder.
requirements.txt : File that tells about what dependencies needed for project
venv : Folder that creates virtual environment for particular project
.env : Stores the Database credentials or secret information of project  (it should be mentioned inside .gitignore)
.gitignore: contains the filename that should be ignored in git commit
templates/index.html and templates/people.html  : This folder contains the all html pages
static/style.css and static/script.js : contains the styling and frontend validations
app.py : Main application code logic
